Pulse Companion Windows x64 · 公开品牌图标版

本程序是独立桌面伴侣，不会修改 Codex 或其他 AI 应用，也不会发送提示词或创建任务。它会在当前用户登录时后台运行；托盘可以退出并暂停自动恢复，开始菜单可手动恢复。

Codex 打开时，伴侣只读查询它的额度和任务；没有登录或不可用时不会用示例数据代替。其他应用仅按打开的桌面窗口显示。Cursor、Claude、Grok Bot 只使用你明确选择的官方网页登录授权；Antigravity 只在你同意后委托已安装的官方 agy CLI（至少 1.1.11）查询额度。全部默认关闭，不继承源码版的第三方授权。公开版不包含读取其他应用会话、解密其本地登录存储或从进程内存提取认证信息的实现。

随时可以按应用停止读取，不影响 Codex 正常运行，不改变原应用登录。卸载会移除本版程序与后台入口，保留关注、个人设置及已有备份。

需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Evergreen Runtime。公开版只包含品牌图标，不含本机专用机器人素材；不会覆盖已经启用的本机专用版或旧版。
